# Plastic Surgery Research Platform (Landing Page MVP)

Trust-centered landing page for a research platform that helps people evaluating plastic surgery (especially rhinoplasty) in Georgia find structured, evidence-based information about surgeons.

## What this is
- A **research platform** landing page (not a clinic site)
- **Mock data only** (no backend, no auth)
- Next.js App Router + TypeScript + Tailwind CSS

## Run locally
This environment doesn’t include `npm`, so install Node.js (with npm) locally, then:

```bash
cd plastic-surgery-research-platform
npm install
npm run dev
```

## Lint
```bash
npm run lint
```
